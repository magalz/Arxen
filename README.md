# Arxen

Assistente jurídico para advogados no Brasil.

Este repositório está na etapa de preparação da infraestrutura de desenvolvimento.
A especificação funcional orienta as entregas posteriores; a fundação de testes
não representa a implementação do alpha.

Todo comportamento será desenvolvido com TDD: teste significativo, falha esperada,
implementação mínima e refatoração com os testes passando.
